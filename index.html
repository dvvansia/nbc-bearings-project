THE
PROBLEM

NBC Bearings · GINOTECH 2025 · Research Publication

Manual bearing defect detection in manufacturing is slow, subjective, and prone to human error. Quality inspectors must examine thousands of bearings daily, identifying surface defects, cracks, and dimensional inconsistencies.


This project automated the detection process using machine learning and computer vision, achieving real-time classification of OK and NOT OK bearings with high accuracy. The system reduces inspection time from minutes to milliseconds per bearing while maintaining consistent quality standards.

CNN
ARCHITECTURE

TensorFlow · Keras · Image Classification

The convolutional neural network processes bearing images through multiple convolutional and pooling layers, automatically learning hierarchical features from edges to defect patterns.


Input images are resized to 224×224 pixels, normalized, and augmented with rotation, zoom, and shifts to improve model generalization. The architecture includes Conv2D layers with ReLU activation, MaxPooling2D for dimensionality reduction, Dropout layers to prevent overfitting, and Dense layers for final binary classification.

INPUT SIZE 224 × 224 px
FRAMEWORK TensorFlow / Keras
LAYERS Conv2D + MaxPooling
REGULARIZATION Dropout
OUTPUT Binary Classification

TECHNICAL
SPECIFICATIONS

Implementation Details

Image Preprocessing: Rescaling to 0–1 range, histogram equalization for contrast enhancement, noise reduction using Gaussian blur.


Data Augmentation: Random rotation (±15°), width/height shift (10%), zoom (10%), horizontal flip, brightness adjustment.


Training: Binary cross-entropy loss, Adam optimizer, batch size 8, 50+ epochs with early stopping, 80/20 train-validation split.


Evaluation Metrics: Accuracy, Precision, Recall, F1-Score, Confusion Matrix, ROC-AUC curve.
