# Bearing Defect Detection | NBC Bearings Portfolio

## Project Overview

**Internship:** National Engineering Industries (NBC Bearings)  
**Duration:** July 2024  
**Domain:** Machine Learning, Computer Vision, Quality Assurance Automation  

This project automated bearing defect detection in manufacturing using convolutional neural networks (CNNs) and computer vision. The system classifies bearings as OK or NOT OK in real-time, reducing manual inspection time and improving consistency.

## Technical Stack

- **Frameworks:** TensorFlow, Keras, OpenCV
- **Algorithms:** CNN, YOLOv8, Image Classification
- **Languages:** Python
- **Application:** Industrial Quality Assurance

## Key Features

1. **Automated Defect Detection** - Real-time classification of bearing defects
2. **CNN Architecture** - Custom convolutional neural network for feature extraction
3. **Data Augmentation** - Rotation, zoom, shift, flip for robust training
4. **Binary Classification** - OK vs NOT OK bearing categories
5. **Visual Output** - Bounding box annotations with confidence scores
6. **Research Publication** - Published at GINOTECH 2025
